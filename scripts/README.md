# 🚀 Cómo Ejecutar un Script

Desde la raíz del proyecto:

```bash
pnpm exec tsx scripts/<nombre_del_script>.ts
```

---

## 🧭 Con Orden de Ejecución

```bash
pnpm exec tsx scripts/ejemplo.ts
```

---

## ⚡ Sin Orden de Ejecución

```bash
pnpm exec tsx scripts/ejemplo.ts
```
